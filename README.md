## SunnyLand 

This is a 2D Platformer game developed as part of the Introduction to Game Programming (BIM449) course.

## Features
-   **Engine:** Unity 2020.3.9f1
-   **Assets:** [Sunnyland Asset Pack](https://assetstore.unity.com/packages/2d/characters/sunny-land-103349)
-   **Tutorials:** [Platformer Tutorial](https://www.youtube.com/playlist?list=PLpj8TZGNIBNy51EtRuyix-NYGmcfkNAuH)
-   **Genre:** 2D Platformer / Side-scroller

## Controls
- **Move:** A / D or Arrow Keys
- **Jump:** Space
